# Дом · учёт взносов на консьержа

Две самостоятельные страницы без ChatGPT и без входа в Google/GitHub:

- Простая форма: https://pedovochkin.github.io/dom-kassa/
- Панель управления: https://pedovochkin.github.io/dom-kassa/admin.html

Квартиры 65–96. Квартира 91 — 1 000 ₽/месяц, 87 — 1 100 ₽/месяц, остальные — 1 300 ₽/месяц. Общий план — 41 100 ₽, зарплатный план — 40 000 ₽. Фактические выплаты вводятся отдельно.

## Общий журнал

Google Таблица — единственный источник данных: https://docs.google.com/spreadsheets/d/1s2A55qgdIXGWw8YDy9T4tkcaHQdy3CR35_Nygzjt6M8/edit

Страница обращается напрямую к Google Apps Script. Хостинг фронтенда — GitHub Pages. Серверы ChatGPT, D1 и Sites для работы не нужны. Доступность GitHub и Google у конкретного провайдера проверяется отдельно.

Платежи, расходы, тарифы и параметры дома загружаются из таблицы. Ручные правки таблицы больше не заменяются снимком с другого сервера. Тарифы: `Настройки!A18:B49`; суммы указаны в рублях. После изменения тарифа обновите страницу сайта. Тарифы применяются ко всем месяцам, суммы уже записанных платежей не меняются. Переплата остаётся в месяце платежа; для переноса исправьте/разделите платежи в панели.

## Панель управления

Вход по отдельному длинному ключу. Сам ключ не хранится в исходниках и не включён в сборку. В Apps Script находится только SHA-256 хеш. Ключ передаётся серверу в теле HTTPS POST, в браузере хранится до закрытия вкладки. Секретная ссылка с `#key=` убирает ключ из адресной строки после открытия. Не пересылайте её консьержу; для обычного ввода используйте главную страницу.

Панель позволяет менять сумму, квартиру, месяц и дату платежа; исправлять и добавлять расходы; менять название дома, начальный остаток, начало учёта, зарплату и взнос каждой квартиры. Конфликтующие правки отклоняются с предложением обновить журнал.

Удаление исключает запись из расчётов, сохраняя её исходную сумму. До/после исправления сохраняются в скрытом листе «История изменений». Таблица открыта для просмотра по ссылке; скрытые листы не являются механизмом секретности и не содержат ключей.

## Разработка и публикация

Node.js 22.13+:

```sh
npm ci
npm test
npm run dev
npm run build
```

GitHub Actions проверяет и публикует каждый push в `main`. Отдельные HTML-страницы обеспечивают прямые ссылки без серверного роутера.

Серверный код — `apps-script/Code.gs`. После его изменения обновите существующее развертывание Google Apps Script новой версией, сохранив URL, выполнение от имени владельца и доступ «Все». Не создавайте ключи или Google-учётные данные в репозитории.

Проверки покрывают индивидуальные тарифы, недоплаты/переплаты, повторные запросы, права администратора, редактирование и конфликты, удаление с историей, расходы и чтение тарифов непосредственно из таблицы.
